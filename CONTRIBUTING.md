# Contributing

Corrections and suggestions are welcome.

## Suggesting a course

The bar is deliberately high: an entry must be the **best available option for a specific stage of a specific path**, not merely a good course. When opening a PR or issue, state:

- Which path and stage it belongs to, and **which existing entry it should replace or complement** (and why).
- Cost model (free / free to audit / paid).
- A link that loads and is likely to stay stable (prefer the course's long-lived page over a year-specific one).

## Corrections

Courses get retired and links rot. If an entry is dead, renamed, or no longer maintained, open an issue or PR — the link checker runs weekly, but human judgment catches staleness that HTTP 200 doesn't.

## Style

- One course per row; the "Why this one" cell must argue, not describe.
- No affiliate links, no self-promotion of paid products.
- Keep the opinionated tone: this is a guide, not a directory.
